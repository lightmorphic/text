Accessibility

This website is built to work well for everyone: it follows the WCAG 2.1 AA contrast rules, every control can be reached with the keyboard and shows a visible focus outline, images carry written descriptions, and colour is never the only way something is communicated. It works at any window size without sideways scrolling.

The app aims for the same: keyboard-reachable controls, labelled buttons, and status shown in words as well as colour.
